# callmesoul.github.io

CallMeSoul 的 Hexo 博客，使用 [soul-blog-theme](https://github.com/callmesoul/soul-blog-theme) 的 Hexo 适配版。

## 本地开发

```bash
npm install
npm run dev
```

开发服务默认地址为 <http://localhost:4000/>。

## 生成静态站点

```bash
npm run build
```

生成结果位于 `public/`。

## 主题来源

`themes/hexo` 从 soul-blog-theme 的 `themes/hexo` 引入，并包含主题运行所需的图片和音频资源。当前基于上游提交 `2afa6d1`（v1.5.1）。
